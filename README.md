# PagePure · 网页净化助手

把网页里不想看的区域隐藏起来，让阅读更清爽。**手动隐藏免费使用，不需要注册，也不需要 API 密钥。**

## 下载安装

适用于 Chrome、Edge 和星愿浏览器。已发布下载版本：**0.6.32**；当前本地开发版本：**0.7.5**（已提交 Edge 商店审核，过审后可[从 Edge 商店安装](https://microsoftedge.microsoft.com/addons/detail/ijiaoneehjiebocilhnbmkoohlleaeen)）。

1. **[点击下载安装包](https://github.com/mhgd3250905/PagePure/releases/download/v0.6.32/PagePure-0.6.32.zip)**，解压到一个固定文件夹。
2. 打开浏览器的“扩展管理”页面：Chrome 在地址栏输入 `chrome://extensions`，Edge 输入 `edge://extensions`；星愿从菜单进入扩展管理。
3. 开启 **开发者模式**，点击 **加载已解压的扩展程序**（有的浏览器叫“加载解压缩的扩展”）。
4. 选择刚才解压后**包含 `manifest.json` 的文件夹**，然后刷新要净化的网页。

安装后请保留这个文件夹，不要删除。无需下载 GitHub 的“Source code”，也不用安装 Node.js。

## 开始使用

1. 点击网页左下角 **PagePure → 选择要隐藏的内容**。
2. 点选不想看的区域，用 **扩大／缩小** 调整范围。
3. 点击 **隐藏区域 → 保存更改**，下次打开会自动应用。

想恢复内容：在选择模式里选中对应区域，点击 **恢复区域 → 保存更改**。只想修改当前网页，点操作条上的 **“···”** 使用“仅本页”操作。

左下角操作台还可以切回原网页、或进入 **设置**，按地址查看和清理规则。

**智能拆分是可选功能**：只有使用它或自动 AI 判断时，才需要在“自动判断与设置”中填写自己的 Jev API 密钥并启用该网站。普通扩大、缩小、隐藏和恢复不需要。

可选的 AI 补充净化在规则应用、页面显示后异步运行，不等待 Jev 才显示页面。明确隐藏或保留的区域不交给 AI；其余区域按你填写的需求判断，不确定时保留。已有规则不再停用整个页面的 AI 判断。

建议需求格式（也可自行编写）：

> 屏蔽：商业广告、付费推广、赞助内容、诱导下载或购买的营销模块

在“自动判断与设置”中配置 Jev 密钥、开启此网站的 AI 判断并保存需求。AI 结果仅临时隐藏，不写入手动规则；可切回原网页，进入选择模式恢复并保存需要保留的区域。

## 更新与常见问题

- **更新**：从 [最新版下载页](https://github.com/mhgd3250905/PagePure/releases/latest) 下载新包，解压并替换原安装文件夹中的文件，然后在扩展管理页点击“重新加载”，再刷新网页。无需先卸载，避免丢失本机规则。
- **找不到左下角入口**：安装或更新后刷新网页；浏览器设置页、扩展商店等内部页面不支持。
- **旧版同类隐藏失效**：0.6.32 已移除类别净化，请按具体区域重新选择并保存。

规则和设置保存在本机。启用可选 AI 功能时，会将处理所需的模块文字、图片描述和链接路径发送给 TypeSafe；详见 [隐私说明](assets/store/privacy-policy.md)。
