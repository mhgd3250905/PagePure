## 0.6.28 净化扫描性能

有规则时每批页面变化不再立即扫描后又重复延迟扫描；仅手动区域规则跳过智能分块采集。浮动元素补扫跳过已识别内容块的整个子树，选区滚动定位每帧最多一次。保留动态新增内容的即时防闪、快照匹配及原首屏显示策略，不清理用户缓存或规则。模拟长页对照验证扫描成本下降，尚未完成用户 Edge 与 Chrome 同网址实测。

## 0.6.27 净化规则管理

从左下角操作台点击“管理净化规则”，在新标签页集中查看所有已保存的地址和规则数量。支持搜索地址、单选、多选和全选搜索结果，确认后批量清理。网站共享规则、具体页面例外及旧版页面类型规则分别展示；清理仅影响勾选的范围，未选中的共享规则仍可能作用于该页面。列表数量包含隐藏与恢复规则，不是页面上被隐藏的元素数量。

清理同步通知相关网页，并结束未保存的选区编辑；保留密钥、AI 开关和自动净化需求。对应网站的旧撤销记录失效，避免已清理规则被撤销操作恢复。规则在确认期间变化时，需要刷新后重新确认。

## 0.6.26 恢复智能拆分入口

“智能拆分”与扩大、缩小位于默认可见的选区行，不再收进更多或因 AI 未配置而消失；未配置时点击显示启用提示。

## 0.6.25 紧凑分组操作条

点选面板限制为 320px 宽，靠边自动定位；隐藏与恢复按“此区域”和“仅本页”分组成对展示。按钮采用明确边框、浅色底和交互反馈，保存为主要操作；移除面向用户的规则清单、范围选择器和冗长统计说明。已有规则、快照和密钥沿用。此版本仅本地交付，尚未提交商店。

## 0.6.24 长区域盖章定位

净化盖章随区域在视口内的可见部分居中，修复长侧栏或滚动后盖章落在屏幕外、只见模糊的问题。保留原有盖章样式、遮罩范围和点选操作。

## 0.6.23 恢复块点选展示

恢复 0.6.21 的块点选工具条及区域展示，只保留左下入口与展开设置的美化。原右上角说明框不再单独显示，附加操作放回点选菜单的更多中。净化规则及快照不变。

## 0.6.22 精简操作界面

移除编辑状态右上角说明面板，将隐藏、恢复、预览、保存与退出集中到点选菜单；页面例外、范围和类别规则收纳在更多操作。左下角入口与展开设置统一为轻量圆角界面，设置默认折叠，减少重复说明。已有规则、快照和净化逻辑保留。

## 0.6.21 区域状态继承

浏览时，已确认的父区域保留为一个判断单位：内部普通子内容（包括新加载的 article、section 等）默认沿用父区域的显示或隐藏，不再逐个等待分类或自动拆分。只在已知边界内继承；区域外新增模块和身份变化的区域继续识别。继承结果不保存为子节点的独立判断。

明确指定的子区域隐藏仍生效，同一范围内可以覆盖父区域的普通保留；仅当前页面的例外优先级仍高于共享规则。子区域明确恢复时继续保留原有防误隐藏行为，必要时放行包围它的隐藏父区域。已保存的手动拆分仍让子区域独立判断，选择编辑模式也保留内部选择能力。更新后刷新即可沿用已有区域快照与规则。

## 0.6.20 正文快照恢复

增加按具体网址保存的稳定区域快照：已识别区域通过唯一定位和自身语义身份恢复，内部正文、点赞数、图片、按钮、加载占位及外围布局变化不再导致整块重新等待分类或自动拆分。身份变化、定位不唯一及新区域仍需判断，页面例外与显示优先级不变。不同回答页分别保存，避免同类型页面互相覆盖快照。

每轮净化共用描述与类别结果，空类别集合不再重复解析正文；扩展自己写入的可见性标记不触发重复整页扫描，网站移除标记仍及时修复。旧的内容/结构快照继续作为回退，成功识别后自动积累新版快照，无须清空旧规则。更新后第一次打开可能仍需完成一次识别；待内容显示后稍等片刻，再刷新或重新进入测试快速恢复。也可在识别完成后点击保存，立即写入新版快照。

## 0.6.19 滚动时保持净化状态

动态更新时只修改发生变化的显示状态，不再先恢复全部隐藏区域再重新隐藏；异步读取规则期间保留已应用的净化状态。已隐藏模块即使尺寸为零或位于阅读区外，仍参与后续判断；内容被复用后需要重新识别时保持隐藏，确认恢复或识别失败后放行。原网页切换、禁用、页面例外恢复等操作仍正常生效。升级后刷新网页即可，已有规则无需重新保存。

## 0.6.18 当前页面例外

选择区域后，在快捷工具条“更多”或面板“仅当前页面”中使用“仅当前页面隐藏”与“仅当前页面恢复”，再保存。普通隐藏与恢复仍沿用所选范围，默认整个网站共享；页面例外只影响当前具体网址（路径及查询参数，不含 hash），不会扩展到所有问题页。

页面例外优先于普通规则，同一层级仍显示优先。例如问题页仅当前页面隐藏，不影响首页；全站隐藏后，也能单独恢复首页。再次对同一区域执行普通隐藏或恢复，会替换当前编辑范围中的本页例外，其他页面例外不变。更多选项的规则列表可删除本页例外以恢复共享行为；取消不保存，撤销仍恢复上次保存的规则。

页面例外与共享规则一起保存并进入现有快照与撤销流程。没有稳定定位的区域不会偷偷改成全站同类隐藏，请先调整选择范围。原有快照无需清理。

## 0.6.17 快速恢复快照

保存并应用会等待本地分类快照写入成功。快照同时记住已识别的隐藏与保留模块；再次打开同类型页面时，优先用精确内容或稳定结构恢复，标题、链接和图片地址更新不再必然等待 AI。命中的模块不重复分类，未命中的新结构仍按原流程判断。

结构快照按页面类型与规则版本隔离；同一结构出现不同类别时停止结构复用，避免已观察到的广告与内容混排被合并。写入失败会提示再次保存。升级后请进入选择界面，待识别完成后再保存一次，以建立新结构快照。网站结构变化或没有稳定结构锚点的模块仍可能需要等待识别。

网页净化的基本操作是：点选区域、选择处理方式、预览、保存。无需理解 DOM、选择器或模型分类；手动区域选择不需要 API Key。

## 使用

重新加载 `E:\AII-Jev\zhihu\extension` 并刷新网页。点击角落悬浮按钮，再点“选择要隐藏的内容”。

点击蓝框只会选中目标，不会立即隐藏整类。选择：

- **隐藏区域**：记住这个区域的稳定结构。
- **隐藏同类**：使用 Jev 识别结果选择当前页面同类模块，后续内容继续判断。
- **恢复区域**：明确保留该区域。同一层级显示优先；保护区域位于待隐藏父容器内时，保留父容器，避免连带隐藏。页面例外优先于普通规则。

顶部提供扩大、缩小范围；“···”中的“调整分类”提供类别纠正。橙色轮廓表示当前目标，毛玻璃遮罩和“净化”盖章表示将隐藏的区域；盖章在当前可见部分居中。先“预览效果”，满意后保存。取消或 Esc 不保存。

“···”中的“仅本页”提供成对的隐藏与恢复操作。界面不再展示高级规则清单和范围选择器；已有规则继续保留。

操作台首屏提供原网页 / 净化效果切换，以及撤销上次保存。临时显示不删除规则，刷新或跳转后恢复正常应用。撤销对当前页面适用的各个范围各恢复一次上次保存；撤销记录持久保存在本机。清除本页规则也清除相应撤销记录。

## 智能识别

在折叠的“自动判断与设置”中配置 Jev API Key，并为当前网站启用 AI 判断。手动操作随时可用；智能同类选择需要模型。

内置 27 类（包含无法确定），覆盖阅读、课程、活动、商品、职位、开源项目、直播、社区、广告、会员、账户等。判断综合模块功能、内容对象、所在区域、近邻容器、栏目标题和商业属性，避免把所有列表都视为普通信息流。

模型仍可能误判。可通过“调整分类”指定现有类别，并按稳定结构保存纠正；未知模块不会整体视为同类。当前版本尚未提供自动创建新类别、类别合并、自然语言生成规则。这些是后续扩展方向。

## 规则范围

默认作用于整个网站（同一来源，协议、端口、子域名分别管理）。“仅本页”操作作用于当前网址（含查询参数，不含 hash）。旧版保存的同类页面规则仍兼容：数字和 UUID 路径段归一化，普通文字 slug 不自动归并。各范围规则叠加，页面例外优先，同一层级保留优先。

保存区域使用稳定定位，不以列表序号或当前文章标题作为兜底。无法稳定定位时会提示调整范围；网站改版可能需要重新选择。类别规则按新内容重新判断，并复用会话缓存。分类策略版本变化会失效旧模型缓存。

已有保存规则时暂停旧的阅读目标自动净化；清除规则后原自动模式可恢复。手动选择可无模型运行，模型失败时保留尚未判断的内容。

## 数据与限制

支持普通 HTTP/HTTPS 网页。图片与 iframe 广告通过外层覆盖层选择，不读取跨域框架内部；不支持封闭 Shadow DOM、Canvas 内部视觉元素和浏览器内部页面。

启用 Jev 后，模块文本、图片描述、结构提示及去除查询参数的链接路径发送到 TypeSafe `jev-latest`。不发送整页 HTML、Cookie、输入框或可编辑区域内容。每批最多 5 块，全局最多 3 个请求并发。密钥仅存在受信任扩展存储，规则在本机。

## 0.6.11 规则隔离与快速恢复

撤回 0.6.1 的首页到 blog 自动继承。首页和文章子域名分别保存 AI 开关、规则及快照；不会将首页偏好混入文章页面。blog 不同作者的文章归入相同页面类型。兼容旧作者路径规则：原作者页面保持原规则；无本页规则时，仅复用旧 blog 文章类别偏好，不跨作者搬运具体选区。

类别判断结果在本机按页面类型与规则版本保存快照，最多 200 个模块。进入页面先恢复内容和结构描述一致的模块，再后台逐批判断；新结果优先，判断变为保留会恢复显示。规则变更会使旧快照失效。内容变化的模块不盲目沿用旧判断，需要重新识别。快照可跨浏览器重启复用，但首次使用新版仍需完成一次识别。手动区域规则本来就直接应用，不需要等待模型。

82 项测试通过，新增慢模型下快照先隐藏、识别后恢复，以及规则版本和来源隔离测试。尚未读取用户浏览器内的具体存储，因此旧规则实际命中情况需刷新扩展后验收。

## 按网站保存阅读需求

0.6.11 将自动净化阅读需求按完整来源保存。CSDN 首页、blog、知乎相互独立；未知网站使用无站名的通用默认。旧全局需求保留在原存储中，仅知乎沿用，其他来源不自动套用无法确定归属的历史需求。此需求仅影响无可视化规则时的自动净化，不参与功能类别判断；因此修改需求不影响类别快照。

0.6.11 点击模块后在区域旁显示快捷工具条：扩大、缩小、选定隐藏、保存。选择阶段以灰色半透明遮罩及“净化”印章标记隐藏区域；保存后仍直接隐藏，不保留占位。区域名称排除脚本、样式和编辑内容，纯图片或 iframe 使用可读的兜底名称。

0.6.11 选择遮罩改为毛玻璃模糊与去饱和效果，采用双层圆形净化徽章；较矮区域自动使用紧凑标记。

0.6.11 遮罩覆盖范围包含选区内脱离父容器边界的 fixed/sticky 后代，滚动后补一次布局更新；支持最小 24px 的固定工具栏，补扫主阅读区域之外及零尺寸容器中的悬浮模块。

快捷操作台以鼠标点击坐标为锚点弹出，扩大/缩小保持锚点，贴边时自动限制在视口内。

0.6.11 document_start 加入首屏显示门控：先保留布局但不显示网页，读取规则和快照；有规则时在 DOM 就绪后同步应用已有判断再放行，不等待 Jev。无规则、关闭、读取失败时立即放行，最长等待 1.5 秒。新出现或快照无法匹配的内容放行后仍由模型后台校正；这减少初始闪烁，但不保证慢网络或持续动态插入页面完全无闪烁。

0.6.11 快捷操作条新增“智能拆分”。将选中父块及最多 20 个不重叠内部候选描述作为 state 交给 Jev，至少确认两个独立模块后更新选框；其他候选仍可选择，避免遗漏。可以重复拆分。需密钥及本站 AI 开关；内容变化、请求失败或模型不确定时保留原区域。拆分结构仅在当前页面会话内保留，使用“选定隐藏”保存子区域规则后，重进仍按其稳定定位应用。

0.6.11 拆分后的无独立标识容器可以使用内部稳定入口链接或语义属性生成定位，避免仅因相同 Card 外壳而退回列表序号。适用于盐言作者平台等服务模块；位置变化和文案更新仍可复用。完全无稳定特征的区域仍会提示调整范围。

## 0.6.13 拆分记忆与经验参考
保存时同时保存模块边界，下次分类前恢复；不再仅限当前页面会话。只有手动智能拆分后保存，才记录同来源、同页面类型的精简拆分示例（最多 3 组）。结构定位无法恢复时，自动对最多 3 个可拆分容器请求 Jev，参考过去示例重新判断当前边界，再分类子模块；失败时保留原有分块。不训练模型、不承诺单次 API 调用，也不以文章文本相等判断类别。自动拆分不反向积累为用户经验。
旧版本没有保存这些边界和经验，因此升级后需对问题区域再拆分并保存一次。分发包：PagePure-0.6.13.zip。

## 0.6.14 重复广告块选择修复
优先使用更高层模块祖先定位重复图片块；已识别类别的区域无法单独稳定定位时，选定隐藏改为选中同类别，并在快捷条显示按类别保存提示。98 项测试通过。

## 0.6.15 待判断区域先隐后显
已有类别净化规则时，快照未命中的模块在判断期间保持透明并禁止点击，确认保留后展示，确认隐藏后移除。动态插入区域在 MutationObserver 回调中立即处理，不再等 200ms 防抖。手动选择、原网页模式、禁用及分类失败时恢复可见；仍保留启动故障超时放行机制。100 项测试通过。

## 0.6.16 网站共享规则
默认按整个来源（协议+主机）保存隐藏偏好，保存时按编辑前规则计算差量，保留其他路由添加的规则。未创建网站规则时，从同来源旧页面规则汇总类别偏好，具体选择器仍保留原范围。分块边界在共享规则中标注页面类型，避免不同布局同名容器互相覆盖。高级选项仍可设置局部规则。不同子域不自动合并。
