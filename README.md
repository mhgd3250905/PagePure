# PagePure · 网页净化助手

把网页里不想看的区域隐藏起来，让阅读更清爽。**手动隐藏免费使用，不需要注册，也不需要 API 密钥。**

## 下载安装

适用于 Chrome、Edge 和星愿浏览器。GitHub 下载版本：**0.7.5**。商店动态（2026-09-24）：Edge 商店 0.7.6 已过审上架（0.7.5 → 0.7.6 自动替换），可查看[Edge 商店页面](https://microsoftedge.microsoft.com/addons/detail/ijiaoneehjiebocilhnbmkoohlleaeen)；Chrome Web Store 0.7.6 审核中，通过后自动发布。

1. **[点击下载安装包](https://github.com/mhgd3250905/PagePure/releases/download/v0.7.5/PagePure-0.7.5.zip)**，解压到一个固定文件夹。
2. 打开浏览器的“扩展管理”页面：Chrome 在地址栏输入 `chrome://extensions`，Edge 输入 `edge://extensions`；星愿从菜单进入扩展管理。
3. 开启 **开发者模式**，点击 **加载已解压的扩展程序**（有的浏览器叫“加载解压缩的扩展”）。
4. 选择刚才解压后**包含 `manifest.json` 的文件夹**，然后刷新要净化的网页。

安装后请保留这个文件夹，不要删除。无需下载 GitHub 的“Source code”，也不用安装 Node.js。

说明：上方下载包是 GitHub 发布的 0.7.5 版本，配置仍在扩展弹窗中；本仓库当前源码为 0.7.6（Edge 商店已上架，Chrome 商店审核中），含独立设置页等改动，源码工作区行为与下载包可能不同。

## 开始使用

1. 点击网页左下角 **PagePure → 选择要隐藏的内容**。
2. 点选不想看的区域，用 **扩大／缩小** 调整范围。
3. 点击 **隐藏区域 → 保存更改**，下次打开会自动应用。

想恢复内容：在选择模式里选中对应区域，点击 **恢复区域 → 保存更改**。只想修改当前网页，点操作条上的 **“···”** 使用“仅本页”操作。

左下角操作台还可以切回原网页。已发布的 0.7.5 下载包在扩展弹窗中管理设置；当前源码候选则会打开绑定当前网页的独立扩展设置页，可管理全局开关、AI 密钥和本站需求，并按地址查看和清理规则。

**智能拆分和自动 AI 判断是可选功能**：只有使用它们时才需要自己的 Jev API 密钥。知乎主站与专栏默认启用 AI 判断，其他网站默认关闭，可在设置中按站点调整；普通扩大、缩小、隐藏和恢复不需要密钥。

可选的 AI 补充净化在规则应用、页面显示后异步运行，不等待 Jev 才显示页面。明确隐藏或保留的区域不交给 AI；其余区域按你填写的需求判断，不确定时保留。已有规则不再停用整个页面的 AI 判断。

建议需求格式（也可自行编写）：

> 屏蔽：商业广告、付费推广、赞助内容、诱导下载或购买的营销模块

在已发布 0.7.5 的浏览器工具栏弹窗，或当前源码候选的独立设置页中配置 Jev 密钥、按需开启站点 AI 判断并保存需求。AI 结果仅临时隐藏，不写入手动规则；可切回原网页，进入选择模式恢复并保存需要保留的区域。

## 更新与常见问题

- **更新**：从 [最新版下载页](https://github.com/mhgd3250905/PagePure/releases/latest) 下载新包，解压并替换原安装文件夹中的文件，然后在扩展管理页点击“重新加载”，再刷新网页。无需先卸载，避免丢失本机规则。
- **找不到左下角入口**：安装或更新后刷新网页；浏览器设置页、扩展商店等内部页面不支持。
- **旧版同类隐藏失效**：0.6.32 已移除类别净化，请按具体区域重新选择并保存。

规则和设置保存在本机。启用可选 AI 功能时，会将所需的可读模块文字、图片描述与路径、结构及嵌入媒体提示、去除查询参数的链接路径发送给 TypeSafe；普通判断与智能拆分的数据范围和上限见[隐私说明](assets/store/privacy-policy.md)。
